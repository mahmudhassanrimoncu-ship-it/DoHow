    HOW TO TEACH YOURSELF THIS

    The copy → change → create loop

    Every phase follows the same rhythm. It works because you are never staring at an empty file.

    1. Copy a small working example and run it unchanged.
    2. Change one thing at a time — a duration, a color, an easing — and predict the result before you save.
    3. Create a tiny scene of your own that uses the idea without looking at the example.
    4. Keep anything reusable in a personal snippets/ folder. That folder becomes your toolkit.
    WHEN YOU GET STUCK
    • Read the types. Hover a component in your editor — the TypeScript definitions are the most complete docs there are.
    • Search old docs too. The API matches Motion Canvas, so Motion Canvas tutorials and examples apply — just change imports from @motion-canvas/* to @canvas-commons/*.
    • Shrink the problem. Make a fresh scene with only the broken element in it.
    • Ask with a repro. Post a minimal scene file in the project's GitHub discussions or community chat.
